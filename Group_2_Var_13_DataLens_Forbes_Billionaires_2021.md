## 2. Подключение данных и подготовка датасета

### 2.1. Подключение и связи

Загрузите в Yandex DataLens четыре файла (или три основных + один дополнительный) в одном подключении типа «Файлы». Проверьте кодировку (UTF-8), разделитель и типы полей.

Создайте датасет на основе подключения и перетащите на рабочую область все таблицы. Установите связи:

1. `Forbes Billionaires 2021` ←→ `Countries Latitude and Longitude` по полям `track_id` = `spotify_id`.
2. `Countries Latitude and Longitude` ←→ `Latitude and Longitude for Every Country` по полям `country` = `country-code`.
3. (Дополнительно) `Latitude and Longitude for Every Country` ←→ `Country Mapping` по полям `country-code` = `alpha-2`.

Тип связи — Left Join. Убедитесь, что к каждому наблюдениеу подтянулись страна прослушивания, координаты страны и регион. Зафиксируйте наблюдения без геоданных и при необходимости исправьте несоответствия в идентификаторах `track_id`.

**Проверка корректности связей:**
- В области предпросмотра отображается объединённая таблица с полями из всех источников.
- Количество строк в основном датасете не уменьшилось (тип Left Join сохраняет все строки основного датасета).
- Для наблюдений, входящих в топ-50 в каких-либо странах, заполнены поля `country`, `latitude`, `longitude`, `region`.
- Отсутствуют дубликаты строк из-за связи «многие-ко-многим».

### 2.2. Вычисляемые поля

Создайте в датасете следующие вычисляемые поля.

**1. Категория целевого показателя — `target_group`:**

```text
CASE
    WHEN [NetWorth] < PERCENTILE([NetWorth], 0.25) THEN "Нижний"
    WHEN [NetWorth] < PERCENTILE([NetWorth], 0.50) THEN "Нижне-средний"
    WHEN [NetWorth] < PERCENTILE([NetWorth], 0.75) THEN "Верхне-средний"
    ELSE "Верхний"
END
```

**2. Производный числовой признак — `Age_norm`:**

```text
IF([Age] > 0, LN([Age]), NULL)
```

**3. Баланс показателей — `balance`:**

```text
ROUND([Age] - [Country], 2)
```

**4. Инвертированный показатель — `inverse_metric`:**

```text
ROUND(1 - [NetWorth], 2)
```

**5. Композитный индекс — `composite_index`:**

```text
ROUND(([NetWorth] * 0.3) +
      ([Age] * 0.2) +
      ([Age] * 0.2) +
      ([Country] * 0.2) +
      ([NetWorth] * 0.1), 2)
```

**6. ГеоКоордината — `ГеоКоордината`:**

```text
CONCAT("[", [latitude], ",", [longitude], "]")
```

После создания поля измените его тип на **Геоточка** (через настройки поля). Это ключевое поле для построения геовизуализаций в задании 3.
